OpenSC8 Mixer

Mixer open source para a mesa de som Fifine AmpliGame SC8 no Linux. Recupera o que o FIFINE Genie fazia no Windows: canais separados por programa, mix de stream para a live e muito mais.

Ver no GitHub Releases

O que ele faz

Canais por programa

Jogo, navegador, chat e música em canais separados, cada um com seu volume.

Fone e live separados

Dois volumes por canal: o que você ouve e o que vai para a transmissão.

SC8 Stream para o OBS

Uma fonte virtual com o mix da live e o seu microfone, pronta para capturar.

Soundboard

Aplausos, risos ou qualquer arquivo seu, tocando no fone e na live.

Botão Game/Chat

As duas saídas da mesa ficam visíveis, então o botão físico volta a equilibrar jogo e chat.

Sem sudo

Instala só para o seu usuário em cima do PipeWire, com desinstalação e rollback.

Instalação

A primeira versão ainda não saiu. O fluxo previsto:

git clone https://github.com/dieguesmosken/opensc8-mixer.git
cd opensc8-mixer
./install.sh

Requer PipeWire 1.0+, WirePlumber, Python 3.10+ e GTK 4. A chave traseira da SC8 precisa estar em PC.

Quer ajudar?

O que mais destrava o projeto agora são capturas USB do FIFINE Genie no Windows, para decifrar EQ, voice changer e luzes. O passo a passo está no guia de hardware, e as regras no CONTRIBUTING.md.
